عکس یا ویدیوی خود را در مخزن شخصی‌تان آپلود کنید. محتوا روی حساب GitHub شما ذخیره می‌شود — کاملاً متعلق به شما.

برای ارسال محتوا وارد GitHub شوید

برای حفظ مالکیت محتوای شما، فایل‌ها در مخزن شخصی شما روی GitHub ذخیره می‌شوند. این کار نیاز به ورود از طریق GitHub دارد.

  • ✓ محتوا روی حساب خود شما ذخیره می‌شود — کاملاً متعلق به شما
  • ✓ در هر زمان می‌توانید محتوا را حذف کنید
  • ✓ ما به پسورد شما دسترسی نداریم — فقط اجازه نوشتن در مخزن
  • ✓ مخزن شخصی شما به‌صورت خودکار ساخته می‌شود (یک‌بار)
