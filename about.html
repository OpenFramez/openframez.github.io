درباره پیکسلری

یک گالری تصاویر بدون سرور، بدون ورود، و کاملاً آزاد.

پیکسلری یک پلتفرم نمایش محتوای بصری است که کاملاً روی GitHub Pages اجرا می‌شود — بدون نیاز به سرور، پایگاه‌داده، یا حتی حساب کاربری برای مشاهده. تمام تصاویر از Wikimedia Commons با مجوز Creative Commons یا مالکیت عمومی (Public Domain) جمع‌آوری شده‌اند و هر عکس همراه با اعتبار کامل عکاس و لینک مجوز نمایش داده می‌شود.

هدف ما ساختن جای‌گزینی ساده، سریع و خصوصی‌ن PRIVACY-first برای شبکه‌های اجتماعی تصویرمحور است: بدون ردیابی، بدون تبلیغات، بدون جمع‌آوری داده، و بدون نیاز به ورود. کافیست آدرس را باز کنید و از گالری لذت ببرید.

ویژگی‌های کلیدی

  • بدون سرور: همه‌چیز روی GitHub Pages اجرا می‌شود — کاملاً رایگان.
  • بدون ورود: برای مشاهده، جستجو یا دانلود نیازی به حساب کاربری نیست.
  • موبایل‌اول: طراحی واکنش‌گرا با اولویت تجربه موبایل — bottom navigation، FAB جستجو، lazy-loading.
  • تم تاریک: پشتیبانی از تم روشن/تاریک با ذخیره تنظیمات کاربر.
  • PWA: قابل نصب روی موبایل و دسکتاپ، با پشتیبانی آفلاین.
  • SEO بهینه: متادیتای کامل، Open Graph، JSON-LD، sitemap.
  • مجوز آزاد: تمام محتوا CC-licensed یا Public Domain.
  • منبع باز: سورس کد روی GitHub به‌صورت عمومی در دسترس است.

معماری فنی

پیکسلری از یک معماری JAMstack استفاده می‌کند: HTML ایستایی که در زمان build تولید می‌شود، داده‌ها در فایل JSON، و تعاملات کلاینت با JavaScript خالص (Vanilla JS) پیاده‌سازی شده‌اند. هیچ build step یا framework پیچیده‌ای وجود ندارد — این یعنی load سریع‌تر، attack surface کمتر، و نگهداری آسان‌تر.

جمع‌آوری داده: داده‌ها با اسکریپت Python از Wikimedia Commons API استخراج می‌شوند و در data/photos.json ذخیره می‌شوند. هر بار اجرای اسکریپت، داده‌های تازه‌ای دریافت می‌شود.

نقشه راه

پیکسلری در فازهای مختلف توسعه داده می‌شود. در فاز ۱ (نسخه فعلی)، تمرکز روی گالری تصاویر است. در فازهای بعدی قصد داریم:

  • فاز ۲: افزودن ویدیوهای کوتاه از Internet Archive
  • فاز ۳: موسیقی از Free Music Archive
  • فاز ۴: اپلیکیشن اندروید برای ارسال آسان محتوا
  • فاز ۵: عوامل هوش مصنوعی برای مرور و تأیید محتوا
  • فاز ۶: بازار نرم‌افزار آزاد

برای جزئیات کامل، به سند نقشه راه مراجعه کنید.

مشارکت

پیکسلری یک پروژه منبع‌باز است و از مشارکت community استقبال می‌کند. برای افزودن عکس‌های خود، اشکالات را گزارش کنید، یا ویژگی‌های جدید پیشنهاد دهید، به صفحه ارسال محتوا یا مخزن GitHub مراجعه کنید.

حریم خصوصی

پیکسلری هیچ داده‌ای از کاربران جمع‌آوری نمی‌کند. هیچ analytics، هیچ ردیاب، هیچ کوکی بازاریابی. تنها داده‌ای که ذخیره می‌شود تنظیمات تم شما (روشن/تاریک) در localStorage مرورگر شماست. وقتی صفحه را می‌بندید، هیچ ردی از شما باقی نمی‌ماند.
