ارسال محتوا به پیکسلری

پیکسلری از مدل PR-based CMS استفاده می‌کند: هر عکس از طریق Pull Request به مخزن اضافه می‌شود.

پیکسلری به‌صورت کاملاً غیرمتمرکز کار می‌کند. هیچ کاربری حساب ندارد و هیچ سروری برای آپلود مستقیم وجود ندارد. در عوض، شما عکس‌های خود را به‌صورت فایل در مخزن GitHub قرار می‌دهید و یک Pull Request باز می‌کنید. بعد از بررسی، عکس شما در گالری نمایش داده می‌شود. این روش شفاف، قابل‌audit، و کاملاً free است.

پیش‌نیازها

  • یک حساب GitHub (رایگان)
  • عکس با مجوز آزاد (Creative Commons یا Public Domain) — یعنی عکسی که خودتان گرفته‌اید یا به‌صورت قانونی آزاد شده است
  • ابعاد حداقل 1200px در بزرگ‌ترین ضلع
  • فرمت JPEG، PNG یا WebP
  • حجم فایل کمتر از 5MB (برای thumbnail) — فایل اصلی می‌تواند تا ۲۵MB باشد

مراحل ارسال

۱

Fork مخزن

به صفحه مخزن بروید و روی دکمه Fork در بالا-راست کلیک کنید. یک کپی از مخزن در حساب شما ساخته می‌شود.

۲

عکس خود را آپلود کنید

در fork خود، به پوشه uploads/photos/ بروید. فایل عکس خود را drag-and-drop کنید یا از دکمه Upload files استفاده کنید. نام فایل را به انگلیسی و توصیفی انتخاب کنید، مثلاً sunset-mountains-alborz.jpg.

۳

متادیتا را در data/photos.json اضافه کنید

فایل data/photos.json را باز کنید و یک entry جدید به پایان آرایه photos اضافه کنید. ساختار دقیق در راهنمای مشارکت توضیح داده شده است.

۴

Commit و Pull Request

تغییرات خود را با پیام واضح (مثلاً Add: sunset-mountains-alborz.jpg) commit کنید. سپس به صفحه اصلی fork خود بروید و روی دکمه Compare & pull request کلیک کنید. عنوان و توضیح کامل بنویسید.

۵

بررسی و انتشار

تیم بررسی (فعلاً انسانی، در فازهای بعدی AI) عکس شما را بررسی می‌کند: کیفیت فنی، صحت مجوز، و رعایت قوانین. بعد از تأیید، PR merge می‌شود و عکس شما در عرض چند دقیقه روی گالری نمایش داده می‌شود.

نکته مهم: فقط عکس‌هایی که خودتان حق انتشارشان را دارید ارسال کنید. عکس‌های دارای کپی‌رایت بدون اجازه صریح صاحب، حذف خواهند شد. ارسال متقلبانه محتوای غیرمجاز ممکن است منجر به block شدن حساب GitHub شما شود.

گزارش تخلف

اگر عکسی را می‌بینید که فکر می‌کنید تخلف قانونی است (کپی‌رایت، حریم خصوصی، محتوای غیرقانونی)، لطفاً از طریق GitHub Issues گزارش دهید. در گزارش خود لینک عکس، دلیل گزارش، و (در صورت وجود) لینک منبع اصلی را ذکر کنید. تمام گزارش‌ها در کمتر از ۴۸ ساعت بررسی می‌شوند.

سوالات متداول

آیا برای ارسال محتوا باید برنامه‌نویس باشم؟

در فاز فعلی (MVP)، بله — شما باید با GitHub آشنا باشید. در فاز ۴، اپلیکیشن اندروید برای کاربران غیرفنی در دسترس قرار خواهد گرفت که کل فرآیند را به چند کلیک ساده تبدیل می‌کند.

چه نوع محتوایی مجاز است؟

هر محتوای بصری باکیفیت که: (۱) شما حق انتشار آن را دارید، (۲) با مجوز Creative Commons یا Public Domain منتشر می‌شود، (۳) شامل محتوای غیرقانونی، توهین‌آمیز یا NSFW نیست. برای راهنمایی بیشتر، سند قانونی را ببینید.

چقدر طول می‌کشد تا PR من بررسی شود؟
